# 🎯 Objetivo del repositorio

Este repositorio tiene como finalidad:

- Documentar máquinas resueltas en HackTheBox.
- Mejorar habilidades en pentesting real.
- Practicar enumeración, explotación y escalada de privilegios.
- Construir una base de conocimiento personal en ciberseguridad.
- Mantener un registro organizado de aprendizaje continuo.

---

# 🛠 Metodología

En cada máquina se sigue un flujo de trabajo general:

1. Enumeración (Nmap, Gobuster, FFUF)
2. Análisis de servicios
3. Explotación inicial
4. Obtención de acceso
5. Escalada de privilegios
6. Documentación completa
